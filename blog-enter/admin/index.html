输入访问口令

访问口令以 PBKDF2-SHA256 哈希保存在服务器上的 .admin/passphrase.json，不存明文。区分大小写，首尾不要带空格。

连续输错会进入冷却（最长 30 秒），冷却期内正确口令也会被拒 —— 看到"尝试过于频繁"就等半分钟再试。
改口令 / 忘了口令，在服务器上执行：
node /srv/blog/repo/blog-enter/server/dev-server.mjs --set-pass（改）
node /srv/blog/repo/blog-enter/server/dev-server.mjs --verify-pass（只验，不触发冷却）
node /srv/blog/repo/blog-enter/server/dev-server.mjs --clear-pass（清除）
